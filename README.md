## 💽 프로젝트  
제 깃허브에 방문해 주셔서 감사합니다.  
저는 단순히 기능 구현을 넘어 **메모리 최적화 그리고 팀의 개발 생산성 향상**을 치열하게 고민하는 클라이언트 프로그래머입니다.  
아래에서 저의 고민이 담긴 프로젝트들을 확인하실 수 있습니다.

<br>

### 1. [디버그(Debug]
> 개발하는 저조차 재밌어서 매일 테스트가 기대됐던 생존 탄막 로그라이크 게임입니다.
* **Tech:** Unity 2D, C#
* **Key Contributions:**
  * 위치 데이터를 기반으로 뱀처럼 움직이는 다지류 보스 구현
  * 무기, 발사체 등 상속 패턴 적용을 통한 객체지향 프로그래밍
  * Unity Input System을 활용한 사용자 입력 처

### 2. [Unity ECS mini project] 및 [코드 리뷰/리팩터링 자동화 툴]
> Data-Oriented Design을 적용하여 대규모 오브젝트 연산을 최적화한 프로젝트입니다.
* **Tech:** Unity ECS, C#
* **Features:**
  * 멀티스레딩 환경(Job System)의 구조적 변경(Structural Change) 에러를 방지하기 위해 **Entity Command Buffer(ECB)** 도입
  * **Burst Compiler** 옵션의 적용으로 CPU 성능 최적화 달성
  * MonoBehaviour 기반으로 동일한 로직을 구현하여 성능 비교
* [🔗 상세 포트폴리오 보기](https://www.notion.so/Unity-ECS-mini-project-35ba6c1ebfc7800994b4f015fd433c3a?source=copy_link) | [🔗 소스 코드 보기](https://github.com/YoungSi4/Sweepers-in-Unity-ECS) | [🔗 블로그 개발 일지 보기](https://blog.naver.com/dksdudgns666/224235003495)
